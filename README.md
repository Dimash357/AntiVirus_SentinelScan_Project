# SentinelScan

SentinelScan — простой локальный сканер файлов на Python с графическим интерфейсом.

Программа позволяет выбрать файл и проверить его несколькими способами: через ClamAV, YARA и набор собственных эвристических проверок. Дополнительно для каждого файла рассчитывается SHA-256 хеш.

Проект рассчитан в первую очередь на обучение и локальную проверку файлов. SentinelScan не является полноценной заменой современному коммерческому антивирусу.

## Возможности

* графический интерфейс на Tkinter;
* проверка файлов через ClamAV;
* дополнительная проверка через YARA;
* расчёт SHA-256;
* базический статический анализ файла;
* обнаружение подозрительных расширений;
* обнаружение двойных расширений вроде `document.pdf.exe`;
* поиск некоторых подозрительных команд и конструкций;
* определение Windows PE-файлов;
* итоговый статус:

  * `CLEAN` — подозрительных признаков не обнаружено;
  * `SUSPICIOUS` — найдены подозрительные признаки;
  * `MALICIOUS` — ClamAV обнаружил вредоносный файл;
* история предыдущих проверок;
* подробный вывод результатов;
* программа не удаляет и не изменяет проверяемые файлы автоматически.

## Как это работает

При проверке файла SentinelScan выполняет несколько этапов.

### 1. SHA-256

Сначала программа рассчитывает SHA-256 хеш файла.

Это позволяет однозначно идентифицировать конкретную версию файла и использовать полученный хеш в дальнейшем для дополнительной проверки.

### 2. Эвристический анализ

Затем программа выполняет базовый статический анализ.

Она может обратить внимание, например, на:

* подозрительные расширения;
* двойные расширения;
* PowerShell;
* `cmd.exe`;
* `wscript.exe`;
* `cscript.exe`;
* `rundll32.exe`;
* `regsvr32.exe`;
* `mshta.exe`;
* некоторые конструкции загрузки или выполнения кода.

Важно понимать, что обнаружение такой строки само по себе не означает, что файл является вирусом. Например, легитимная программа тоже может использовать PowerShell.

Поэтому результаты эвристического анализа считаются подозрительными признаками, а не доказательством заражения.

### 3. ClamAV

Основной антивирусный анализ выполняется через ClamAV.

ClamAV использует собственную базу сигнатур и дополнительные механизмы анализа.

Если ClamAV сообщает об обнаружении вредоносного объекта, SentinelScan устанавливает результат:

```text
MALICIOUS
```

ClamAV необходимо устанавливать отдельно от Python-приложения.

### 4. YARA

Если установлен пакет `yara-python`, программа также выполняет дополнительную проверку через встроенные YARA-правила.

YARA используется как дополнительный источник информации и не заменяет ClamAV.

Если YARA находит совпадение, результат будет:

```text
SUSPICIOUS
```

если ClamAV при этом не обнаружил malware.

## Требования

Для запуска необходим:

* Windows, Linux или macOS;
* Python 3.10 или новее;
* Tkinter.

На Windows Tkinter обычно устанавливается вместе с обычной установкой Python.

Для основной антивирусной проверки нужен ClamAV.

YARA является дополнительной зависимостью.

## Установка

### 1. Клонирование проекта

```bash
git clone https://github.com/Dimash357/AntiVirus_SentinelScan_Project.git
cd AntiVirus_SentinelScan_Project
```

Если проект скачан архивом, этот шаг можно пропустить.

### 2. Установка Python-зависимости YARA

```bash
pip install yara-python
```

YARA можно не устанавливать. В этом случае программа продолжит работать, но проверка YARA будет недоступна.

### 3. Установка ClamAV

Установите ClamAV для своей операционной системы.

После установки необходимо убедиться, что команда `clamscan` доступна из терминала.

Проверить это можно командой:

```bash
clamscan --version
```

Если команда выводит версию ClamAV, всё настроено правильно.

## Обновление базы ClamAV

Перед первым использованием рекомендуется обновить базу сигнатур.

Для этого используется:

```bash
freshclam
```

После обновления ClamAV сможет обнаруживать более актуальные угрозы.

## Запуск

Запустить программу можно командой:

```bash
python main.py
```

После запуска:

1. нажмите `Choose file`;
2. выберите файл;
3. нажмите `Scan`;
4. дождитесь окончания проверки;
5. изучите результат и подробности анализа.

## Результаты

### CLEAN

```text
CLEAN
```

Из доступных проверок не было получено признаков вредоносного поведения.

Это не означает, что файл гарантированно безопасен.

### SUSPICIOUS

```text
SUSPICIOUS
```

Программа обнаружила подозрительные признаки.

Это может быть как вредоносный файл, так и совершенно легитимная программа.

Для такого результата рекомендуется выполнить дополнительную проверку другим антивирусом или сервисом анализа файлов.

### MALICIOUS

```text
MALICIOUS
```

ClamAV сообщил об обнаружении вредоносного объекта.

Такой файл лучше не запускать.

## История проверок

После проверки программа сохраняет краткую историю в файл:

```text
~/.sentinelscan_history.json
```

В истории сохраняются:

* дата проверки;
* путь к файлу;
* SHA-256;
* итоговый результат;
* результат ClamAV;
* результат YARA.

История используется только для локального журнала.

## Безопасность

SentinelScan специально не удаляет файлы автоматически.

Это сделано намеренно. Антивирусная эвристика может ошибаться, поэтому автоматическое удаление подозрительного файла может привести к потере данных.

Программа также не запускает проверяемый файл.

## Ограничения

SentinelScan — небольшой локальный проект, а не полноценный антивирусный продукт.

У него есть несколько важных ограничений:

* эвристический анализ достаточно простой;
* встроенные YARA-правила предназначены в основном для демонстрации;
* программа не выполняет полноценный поведенческий анализ;
* она не заменяет защиту в реальном времени;
* обнаружение неизвестного malware не гарантируется;
* отсутствие обнаружений не гарантирует безопасность файла;
* для актуальной проверки ClamAV должна иметь свежую базу.

Для защиты компьютера в реальном времени рекомендуется использовать полноценный антивирус, например Microsoft Defender.

## Дисклеймер

SentinelScan предоставляется в образовательных целях.

Автор не гарантирует обнаружение всех существующих вредоносных программ. Результат `CLEAN` не следует рассматривать как абсолютное подтверждение безопасности файла.

Не запускайте подозрительные файлы только потому, что SentinelScan не обнаружил в них угрозу. Для важных или неизвестных файлов рекомендуется использовать несколько независимых средств анализа.
